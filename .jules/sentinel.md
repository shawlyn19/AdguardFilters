## 2025-05-22 - [Supply Chain] Transitive Dependency Overrides and GHA Hardening
**Vulnerability:** Transitive dependencies (picomatch, brace-expansion, smol-toml, yaml) were vulnerable to ReDoS and other issues (GHSA-c2c7-rcm5-vvqj, GHSA-3v7f-55p6-f55p, GHSA-v3rj-xjv7-4jmq, GHSA-48c2-rrv3-qjmp, GHSA-f886-m6hf-6m8v). GitHub Actions used mutable tags and lacked explicit permissions.
**Learning:** Standard `npm install` doesn't always resolve nested transitive vulnerabilities if parent packages have restrictive ranges. Explicit `overrides` in `package.json` are necessary. Nested overrides require specific object syntax to avoid 'Override without name' errors when different versions of the same package are needed in the same tree (e.g., picomatch 2.x and 4.x).
**Prevention:** Use exact version pinning for devDependencies. Implement `overrides` for transitive security fixes. Pin GitHub Actions to 40-character commit SHAs and enforce `permissions: contents: read` to minimize attack surface.
