## 2025-05-15 - Improper Dependency Override Breaks ESM
**Vulnerability:** Transitive dependency vulnerabilities in `glob` (GHSA-5j98-mcp5-4vw2), `js-yaml` (GHSA-mh29-5h37-fv8m), and `brace-expansion` (GHSA-v6h2-p8h4-qcjw).
**Learning:** Forcing an override of `brace-expansion` to version 2.x when `minimatch` 10.x is in use results in a `SyntaxError: Named export 'expand' not found`. This is because `minimatch` 10.x expects `brace-expansion` 5.x, which provides ESM named exports, whereas 2.x (which also exists and is patched for the same vulnerability) is a CommonJS module that does not provide these named exports in a way compatible with how `minimatch` imports them.
**Prevention:** When using `overrides` to fix transitive vulnerabilities, ensure the overridden version is major-version compatible with the versions expected by the rest of the dependency tree. Verify the fix by running the affected tools (e.g., `npm run lint`) to catch ESM/CommonJS compatibility issues.
