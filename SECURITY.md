# Security Policy

## Supported Versions

Only the latest version of the filter lists is supported.

## Reporting a Vulnerability

If you find a security vulnerability in our filters or scripts, please do not open a public issue. Instead, report it through one of the following channels:

* **AdGuard Security: security@adguard.com**

We will acknowledge your report and provide a timeline for a fix.

## Scope

This policy covers:
- AdGuard filter rules in this repository.
- Build and linting scripts in this repository.
