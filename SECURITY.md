# Security Policy

AdGuard takes the security of our products and the privacy of our users very seriously.

## Supported Versions

We support and provide security updates for the current version of the AdGuard Filters repository.

## Reporting a Vulnerability

If you have discovered a security vulnerability in this project, please let us know. You can report it through the following channels:

*   **Security Bug Bounty Program:** [https://adguard.com/en/security-bug-bounty.html](https://adguard.com/en/security-bug-bounty.html)
*   **Email:** security@adguard.com

Please provide a detailed description of the vulnerability, including steps to reproduce it. We will acknowledge your report and work with you to resolve the issue as quickly as possible.

**Please do not report security vulnerabilities through public GitHub issues.**
